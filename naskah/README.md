# Naskah HOWCOME

Satu file per judul, masing-masing berisi versi SHORT (sekitar 89 detik) dan YOUTUBE (sekitar 144 detik), ditambah daftar sumber untuk teks di layar.
Estimasi durasi dihitung pada tempo bicara sekitar 156 kata per menit (energik, jelas).

Nama file audio yang dikirim:
- `sleep4h_short.mp3`, `sleep4h_yt.mp3`
- `skipbreakfast_short.mp3`, `skipbreakfast_yt.mp3`
- `sitallday_short.mp3`, `sitallday_yt.mp3`
