# Naskah HOWCOME

Satu file per judul, masing-masing berisi versi SHORT (1 audio, maks 1000 karakter) dan YOUTUBE (maks 1500 karakter), ditambah daftar sumber untuk teks di layar.
Estimasi durasi dihitung pada tempo bicara sekitar 156 kata per menit (energik, jelas).

Batas TTS: **maks 1000 karakter per file audio, termasuk tag** (dikunci). Short = 1 file `<id>_short.mp3` (sekitar 55-60 detik). YouTube = 1 file `<id>_yt.mp3`, maks 1500 karakter (sekitar 85 detik). Lihat `AUDIO_PARTS.md`.
